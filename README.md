# 2GO Feedback Center

**Welcome to the official feedback center of 2GO.**

欢迎来到 2GO 官方反馈中心。

This repository is dedicated to collecting bug reports, feature requests, and user feedback to help us continuously improve 2GO.

本仓库用于收集 Bug 报告、功能建议及用户反馈，帮助我们持续改进 2GO。

---

## 📌 What Can You Do Here? / 你可以在这里做什么？

- 🐛 **Report a Bug / 报告问题**  
  Found something that doesn't work as expected? Let us know.  
  发现程序运行异常或与预期不符？欢迎向我们反馈。

- ✨ **Request a Feature / 提交功能建议**  
  Have an idea that could make 2GO better? We'd love to hear it.  
  有什么能够让 2GO 变得更好的想法？欢迎提出建议。

- 💬 **Join the Discussion / 参与讨论**  
  Share your thoughts, experiences, and suggestions with the community.  
  分享你的使用体验、想法，与其他用户交流。

---

## 📝 How to Submit Feedback / 如何提交反馈

Please choose the appropriate channel:

请根据反馈内容选择合适的渠道：

| Category / 类型 | Where to Go / 提交位置 |
|---|---|
| Bug Reports / 问题报告 | [Open an Issue](../../issues/new) |
| Feature Requests / 功能建议 | [Request a Feature](../../issues/new) |
| General Discussion / 一般讨论 | [Discussions](../../discussions) |

Before submitting a new issue, please check whether a similar report already exists.

提交新的 Issue 之前，请先检查是否已有相同或类似的问题，避免重复提交。

When reporting a bug, please include as much information as possible:

报告 Bug 时，请尽可能提供以下信息：

- 2GO version / 软件版本
- Operating system / 操作系统
- Description of the problem / 问题描述
- Steps to reproduce / 问题复现步骤
- Screenshots or logs (if available) / 截图或日志（如有）

---

## 📋 Community Guidelines / 社区规范

To keep this feedback center helpful and organized, please:

为了保持反馈中心的良好秩序，请遵守以下规范：

- Be respectful and constructive. / 保持尊重，理性交流。
- Search before creating duplicate issues. / 提交前先检查是否存在重复问题。
- Keep discussions relevant to 2GO. / 讨论内容应与 2GO 相关。
- Do not publish passwords, access tokens, or other sensitive information. / 请勿公开密码、访问令牌或其他敏感信息。
- Report security vulnerabilities privately instead of posting them publicly. / 安全漏洞请通过私密渠道报告，不要直接公开。
